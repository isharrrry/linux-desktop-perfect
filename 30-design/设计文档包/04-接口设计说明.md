## 1. 通用约定

### 1.1 库名、入口名与运行时解析

| 项 | 约定 | 依据 |
|---|---|---|
| 托管侧声明名 | 保留上游 `DllImport` 原始库名（`user32.dll`、`gdi32.dll`、`kernel32.dll`、`gdiplus.dll` 等） | ADR-001：托管层只加补丁 |
| 实际文件名 | 映射到自产件 `libwpfwin32.so`、`libwpfgfx_linux.so`、`libwpfwic.so`、`libdwlinux.so` | 概要设计 §2.4 |
| 解析方式 | 统一入口装载与符号解析，不依赖动态链接搜索顺序 | 部署要求可预测 |
| 搜索顺序 | ① 应用输出目录 ② pack 的 native 目录 ③ 系统库路径；自产件优先于系统同名件 | 防止误用系统库 |
| 解析失败 | 库缺失返回 `ERROR_MOD_NOT_FOUND`，符号缺失返回 `ERROR_PROC_NOT_FOUND`，错误行给库名、符号名与已尝试路径 | §10 |
| 缓存 | 按「库 + 符号」缓存解析结果；失败项在进程内不重试 | NF-004 |

**入口表**是解析结果的内存形态，字段固定：`lib`（`.so` 文件名，必须在部署清单内）、`symbol`（C 入口名，区分大小写）、`addr`（函数指针，桩件指向统一错误返回）、`status`（`impl`/`stub`/`gap`）、`hit`（调用命中计数，长跑用于识别热路径与缺口命中）。

### 1.2 结构体布局与断言

| 约定项 | 规则 |
|---|---|
| 类型宽度 | `HANDLE`/`HWND`/`WPARAM` 取指针宽度；`LPARAM` 取有符号指针宽度；`BOOL` 恒 32 位；`DWORD` 恒 32 位 |
| 对齐 | 按 C 自然对齐；显式填充只在上游声明已有填充处出现 |
| 断言方式 | 编译期断言：`sizeof`、`offsetof`、常量值三方相等，不通过即编译失败 |
| 命名 | 结构体与字段名沿用上游声明，不加前缀、不改拼写 |
| 禁止项 | 禁止「同尺寸不同字段顺序」顶替；禁止可变长数组替代固定布局 |

### 1.3 错误码分层

| 层 | 错误族 | 返回形式 | 上抛到托管侧 | 允许静默 |
|---|---|---|---|---|
| L1 装载层 | 库缺失、符号缺失 | `HRESULT_FROM_WIN32(ERROR_MOD_NOT_FOUND / ERROR_PROC_NOT_FOUND)` | `Win32Exception` | 否 |
| L2 调用层 | 参数非法、空指针、句柄失效 | `E_INVALIDARG` / `E_POINTER` / `E_UNEXPECTED` | `ArgumentException` / `Win32Exception` | 否 |
| L3 资源层 | 分配失败、句柄超限 | `E_OUTOFMEMORY` | `OutOfMemoryException` | 否 |
| L4 能力层 | 未实现、DRM、字体缺失 | `E_NOTIMPL` / `E_FAIL` | `NotSupportedException` / `PlatformNotSupportedException` | 否（必须带缺陷或缺口编号） |
| L5 界面层 | 动作被拒、值非法 | D-Bus 错误回复 | 调用方读到明确错误文本 | 否 |

任何一层返回失败，都必须留下一行可检索的错误记录：库名、符号名、参数摘要、返回码。

### 1.4 版本化

| 契约 | 版本载体 | 兼容规则 | 对拍位置 |
|---|---|---|---|
| P/Invoke ABI | `exports.txt` 的 `since` 列 + 编译期断言 | 上游改声明面即重建清单；旧条目只改 `status`，不删行 | TG-001 |
| DUCE 字节流 | 布局表版本号 + 覆盖表 118 行 | 命令 id 不复用；新增命令只追加 | TG-001、TG-003 |
| 框架包 | pack 版本（`10.0.x`）+ `FrameworkList` | 跟随上游 patch（DQ-004）；清单 diff 为空才算通过 | TG-002 |
| IME/无障碍/打印/媒体 | 运行时探测的服务版本 | 低于最低版本即降级并登记，不猜行为 | §5~§8 各门 |

### 1.5 读数与日志

| 事件 | 必带字段 | 落盘 | 判据 |
|---|---|---|---|
| 库解析 | 库名、符号名、结果、已尝试路径 | 进程日志 | ACC-001 |
| 命令解码 | 批序号、命令 id、字节长度、结果 | 渲染日志（可开关） | ACC-006 |
| 帧提交 | 帧序号、窗口 id、像素尺寸、耗时 | 渲染日志 + 读数 | ACC-007 |

### 1.6 接口数据结构约定与数据字典

跨边界的**公共约定**集中在本节；字段级定义不在这里重列，下钻到 §1.6 末尾的四张表（同一字段写两处就会打架，按 [《01-设计总纲与设计基线管理》](01-设计总纲与设计基线管理.md) §2 规则 B 以定义方为准）。

| 约定项 | 规则 | 落点 |
|---|---|---|
| 字节序 | DUCE 命令流与 P/Invoke 结构体一律**小端**，与上游 `dotnet/wpf` 的字节序一致；不引入额外转换层。V2 的 arm64（小端）无需转换；若将来出现大端目标，转换只在解码入口做一次，不散落到字段读取处（该场景待对拍确认） | IF-011、TBL-002 |
| 结构体对齐与填充 | 按上游声明面的自然对齐；不得改字段顺序、不得用同尺寸类型顶替；`sizeof`、`offsetof`、常量值三方相等由编译期断言覆盖，断言不过即编译失败 | IF-006、TBL-002、SAFE-012 |
| 字符串编码 | X11 侧与 D-Bus 侧一律 UTF-8（NUL 结尾）；Win32 ABI 侧一律 UTF-16LE（`W` 系列约定），转换只发生在 ABI 边界；清单与 pack 文本一律 UTF-8 + LF。`WM_*` 携带文本时按 UTF-16 传入，桥内负责转换与长度校验 | IF-002、IF-031、IF-051、TBL-001 |
| 句柄宽度与无效值 | 对外句柄统一 64 位宽；X11 的 `Window`/`Drawable` 为 32 位，进句柄表前零扩展；**无效值固定为 0**，0 号句柄一律 `E_INVALIDARG`，不做「猜最近句柄」 | IF-002、IF-012、TBL-004 |
| 枚举宽度 | 枚举按 4 字节传输（与 Win32 一致）；未登记的枚举值一律 `E_INVALIDARG`，不接受「走默认分支」 | IF-003、IF-005 |
| 数组与可变长参数 | 一律「指针 + 元素个数」传入，不用隐式 NUL 截止；元素个数为 0 时指针必须为 NULL（非 NULL 且个数为 0 视为 `E_INVALIDARG`）；返回数组由调用方分配、被调方填写 | IF-004、IF-013 |
| 空指针与空句柄语义 | NULL 只表示「无」，不表示「用默认值」；需要默认值时由调用方显式填默认值，被调方不替调用方做决定 | SAFE-013 |
| 时间与版本字段 | 时间统一 UTC 毫秒（读数、日志、快照）；版本字段用「主.次.修订」三段整数，pack 侧与上游 `10.0.x` 同格式同口径 | IF-023、IF-073 |
| 对齐与宽度以外的禁止项 | 禁止用「同尺寸不同字段顺序」顶替结构体；禁止用可变长数组替代固定布局；禁止在接口层做隐式单位换算（像素与 pt 的换算只在 MOD-13/24 做） | §1.2、[《03-软件设计说明》](03-软件设计说明.md) §2.3 |

### 1.7 接口安全性设计

接口是全仓最外侧的输入面，安全约束在这里必须落到「检查点 + 失败返回」，而不是原则。威胁模型与违反后果在 [《06-安全性设计支撑材料》](06-安全性设计支撑材料.md) §1~§2；本节只写接口侧的控制点与验证方式（判据落在 08 的测试门，见 [《08-判据先行与界面检测设计说明》](08-判据先行与界面检测设计说明.md) §2）。

| 威胁面 | 典型威胁 | 接口侧控制措施 | SAFE | 验证 |
|---|---|---|---|---|
| P/Invoke 边界 | 伪造句柄、越界指针、`dlsym` 命中非登记符号 | 解析器只认 `exports.txt` 登记项（不做前缀模糊匹配）；句柄进表即校验；参数在入口统一判空与判宽 | SAFE-011、SAFE-012、SAFE-013 | TG-001（ACC-004） |
| DUCE 字节流 | 构造超长命令、越界参数块、引用不存在的资源句柄 | 先校验长度字段再解码；命令 id 必须在 118 条内；资源句柄不在表中即拒绝 | SAFE-006 | TG-001、TG-003（ACC-006） |
| D-Bus（ibus / AT-SPI） | 超长消息、类型伪装、事件风暴 | 消息长度与参数类型白名单；事件节流并计入丢弃计数；总线上来的字符串必须 NUL 结尾 | SAFE-005 | TG-006（ACC-017）、TG-012（ACC-027） |
| CUPS / IPP | 借打印路径写任意文件、伪造作业属性 | 只允许提交作业与查询作业两个方向；不按调用方给的路径写文件；作业属性做范围校验 | SAFE-007 | TG-010（ACC-024） |
| GStreamer | 恶意媒体流触发解码器越界、解码失败被当成功 | 只接受登记容器与编码；解码失败必须报错并停到 `READY`，不静默黑屏 | SAFE-008、SAFE-018 | TG-009（ACC-022） |
| pack 清单 | 伪造件混入产物、身份不一致 | 清单逐件比对 + 反射身份校验；缺件即失败 | SAFE-001、SAFE-004 | TG-002（ACC-003/004） |
| 界面快照 | 快照把敏感文本带出进程 | 脱敏开关默认开启；密码框内容不进快照；快照只落本地读数目录 | SAFE-014 | TG-012（ACC-027） |

**接口控制（谁能调什么）**

| 控制项 | 规则 | 落点 |
|---|---|---|
| 入口白名单 | 只有 `exports.txt` 登记且 `status` 为 `impl`/`stub` 的符号可被解析；未登记符号按 `ERROR_PROC_NOT_FOUND` 处理，不回退到同名系统库 | IF-001、IF-006、TBL-001 |
| 动作白名单 | 无障碍侧只暴露 `click`/`set-text`/`select`/`expand`/`focus`/`scroll` 六个动作；不提供任何「调用任意方法」的通道 | IF-053、SAFE-015 |
| 交互面不监听网络 | 桥只作为 D-Bus 会话总线的客户端连接，不监听 socket、不开放端口 | IF-051、SAFE-016 |
| 打印不写任意路径 | 中间文件只落在进程私有临时目录，作业结束即删；不接受调用方指定的输出路径 | IF-041、SAFE-007 |
| 媒体源范围 | V1 只承诺本地文件与 `file://`；网络 URI 不在 REQ-FN-022 范围内，遇到即返回明确错误，不静默尝试 | IF-061、SAFE-019 |

**输入合理性检查（每条外部输入都要有检查点）**

| 输入 | 检查项 | 检查位置 | 越界处置 |
|---|---|---|---|
| D-Bus 消息 | 总长不超过登记上限（具体数值待对拍确认）、参数个数与类型匹配、字符串 NUL 结尾 | IF-031、IF-051 的入口 | 拒绝并回 D-Bus 错误，计入丢弃计数 |
| DUCE 命令块 | 长度字段 ≤ 剩余字节、命令 id 已登记、参数块对齐、引用的资源句柄存在 | IF-011 解码入口 | 拒绝整批并返回 `E_FAIL`，ACC-006 判红 |
| 图像解码输入 | 像素尺寸 × 通道数 ≤ 登记上限、格式在解码器注册表内、流长度可判定 | IF-003（WIC 调用面） | 返回 `E_INVALIDARG`/`E_OUTOFMEMORY`，不部分绘制 |
| 字体文件 | 表目录长度、CFF 表偏移与字形数上限、循环引用 | [《03-软件设计说明》](03-软件设计说明.md) §3.4.5（MOD-35）入口 | 拒绝该字体并回退到登记回退链 |

| 判据读数输入 | 字段集合、`verdict` 四值枚举、`rc` 与 `verdict` 不矛盾 | IF-073 写入前 | 拒写并标 `FAIL`，不改写成 `SKIP` |

### 1.8 接口错误处理与超时

错误码分两层：对外形态见 §10 错误码总表；内部设计码见 [《03-软件设计说明》](03-软件设计说明.md) §2.1 的 `LDP-E-<域>-<序号>`（一个码只在一个域产生、只在一个模块产生）。超时与重试是**设计上限**，实现阶段可以调低，调高必须同步改判据。

| 接口组 | 错误码来源 | 可重试性 | 超时与取消 | 降级处置 |
|---|---|---|---|---|
| IF-001~IF-006（ABI） | 装载层 `ERROR_MOD_NOT_FOUND`/`ERROR_PROC_NOT_FOUND`、调用层 `E_INVALIDARG`/`E_POINTER`、能力层 `E_NOTIMPL`（§1.3） | 不可重试：装载与断言失败重试无意义 | 无网络超时；同步调用，调用方不得在 UI 线程上做长等待 | 未实现入口返回 `E_NOTIMPL` + 缺陷编号（待缺陷册分配）；库缺失启动失败、退出码 3（SAFE-018） |
| IF-011~IF-014（DUCE） | 解码层 `E_FAIL`/`E_INVALIDARG`；内部 `LDP-E-DUCE-3xx` | 解码失败不可重试（同批终止）；资源表操作最多重试一次 | 单帧提交设计上限 100 ms，超限记告警读数 | 未知命令计数并拒整批，ACC-006 判红；不静默跳过、不画半帧 |
| IF-021~IF-024（框架包） | 构建期错误行 `LDP-E-PACK-2xx` | 不可重试 | 无 | 缺件或身份不符即构建失败（ACC-003/004）；不静默降级为「用系统件」 |
| IF-031（IME） | D-Bus 错误回复 + `LDP-E-IME-6xx` | 可重试：连接断开 3 次，退避 100/300/900 ms | 单次调用设计上限 2 s；取消由会话结束（焦点离开、窗口关闭）显式触发 | 无输入法 → 直接键输入并登记（缺陷编号待分配）；候选窗定位失败 → GAP-003 |
| IF-041（打印） | CUPS 作业状态 + `LDP-E-PRN-8xx` | 可重试：队列不可达 3 次，退避 1/3/9 s；作业被拒不可重试 | 提交设计上限 30 s；取消必须是显式的 Cancel-Job，不允许悄悄丢弃本地作业 | 无 CUPS → `PrintQueue` 明确报错（ACC-024）；不假成功 |
| IF-051~IF-053（无障碍） | D-Bus 错误回复 + `LDP-E-A11Y-7xx` | 可重试：总线重连 3 次，退避 200/600/1800 ms；单次树查询只重试 1 次 | 单次查询设计上限 2 s；快照采集超时 15 s 判红 | 总线缺失 → 桥禁用 + 错误行，读数标 `SKIP` 而非 `PASS`；事件粒度不符 → GAP-012；快照竞态 → GAP-010 |
| IF-061（媒体） | GStreamer 总线错误 + `LDP-E-MED-9xx` | 不支持格式不可重试；设备忙最多重试 1 次 | 状态迁移设计上限 5 s；取消 = 显式 `stop`，状态回 `READY` | 不支持格式必须报错（ACC-022）；无 GStreamer 明确报错（R-006）；DRM 路径返回 `E_NOTIMPL` + D-001 |
| IF-071~IF-073（内部） | 文件写入错误、快照失败 `LDP-E-A11Y-7xx` | 可重试：读数写入 2 次（临时文件 + 改名）；快照重试 3 次，退避 200 ms | 单条判据的超时口径见 [《08-判据先行与界面检测设计说明》](08-判据先行与界面检测设计说明.md) §1.2（判据七字段含 `fail`） | 写失败该条判据标 `FAIL`；不允许静默改成 `SKIP` 或丢弃读数 |

**三条硬规则**：

1. **不可重试类直接失败**：布局断言失败、未实现入口、pack 缺件、不支持格式——立刻失败，留一行可检索的错误记录（库名/符号名或命令 id、参数摘要、返回码），并给出非 0 退出码或明确错误码；重试只会把确定性故障拖成偶发故障。
2. **可重试类有上限与退避**：D-Bus 断开、CUPS 不可达、读数写入——次数上限与退避逐组登记（见上表），不得无限重试与忙等；重试耗尽后按第 1 条处理，读数记下重试次数。
3. **取消必须显式**：关闭窗口、停止播放、用户取消打印、判据超时，都必须先置取消状态再释放资源，并让调用方看到「已取消」；不允许静默丢弃请求，也不允许返回成功却什么都没做。取消后的读数只能记 `FAIL` 或 `DEGRADED`，记 `PASS` 视为判据造假。

**`bounds` 口径：统一为屏幕绝对像素**：

| 项 | 口径 |
|---|---|
| 坐标系 | X11 根窗口绝对像素；相对坐标只在 API 边界内使用 |

| 与上游对照 | `GetWindowRect` 系列同为屏幕坐标，语义对齐、数值可差；差异登记 **GAP-011** |

### 2.3 IF-003 GDI / GDI+

### 2.6 IF-006 exports 清单与对拍

**`exports.txt` 行格式**（列结构定义在 [#出口清单](05-数据与清单设计说明.md) §3.1，此处只定格式规则）：UTF-8 + LF、制表符分隔；`#` 起首的整行为注释，不支持行内注释；必填列为库名、符号名、状态（`impl`/`stub`/`gap`）、责任模块、首次登记版本；按库名分组、组内按符号名字典序（顺序变化不算差异）；不得有空行、尾随空白或重复的「库 + 符号」组合。

| 对拍步 | 动作 | 期望 | 失败判定 |
|---|---|---|---|
| ① 清单自洽 | 解析列数、枚举值、模块名、重复项 | 无解析错误 | 有解析错误即红 |
| ② 符号可解析 | 对每条 `impl`/`stub` 做 `dlsym` 校验 | 全部命中且为函数类型 | 缺一个即红 |
| ③ 布局断言 | 编译 `win32_abi.h` 的断言集合 | 编译期零失败 | 任一断言失败即红 |

断言清单必须覆盖四类面：结构体大小与字段偏移、常量值（`GWL_*`、`SWP_*`、消息常量）、类型宽度（句柄/指针整型/`BOOL`）、函数签名宽度（参数个数与每参宽度）。差异处置固定为：清单多出符号（实现已删）保留条目并改 `status=gap`；实现多出符号立即红，补登记后才能过门；布局差异先改断言再改实现，不允许改断言凑当前布局；上游新增声明按新行追加并把 `since` 填上游版本。

## 3. DUCE 命令流（XIF-002）

### 3.1 IF-011 命令头与布局

命令流字节布局以上游命名结构体为准；本文固定**解码器必须满足的约束**，每条都对应可对拍读数。

|---|---|---|---|

### 3.2 IF-012 资源表与句柄

**句柄是不透明值**：本文不定义位域布局，避免与上游编码假设冲突，只固定表内约束与失效语义。

| 约束 | 要求 | 理由 | 失败处置 |
|---|---|---|---|
| 宽度 | 与托管侧句柄类型等宽（指针宽度） | 跨调用按值传递 | 宽度不符即装载期失败 |
| 零值 | 保留为「无效句柄」，永不分配 | 与 Win32 习惯一致 | 传零即 `E_INVALIDARG` |
| 唯一性 | 同一资源存活期内只有一个句柄 | 视觉树投影需稳定键 | 重复创建告警 |
| 代号 | 槽位复用时递增代号，识别悬空句柄 | 长跑不崩溃（NF-004） | 代号不匹配即 `E_UNEXPECTED` |
| 引用计数 | 绑定 +1、解绑 −1、归零释放 | 资源生命周期 | 计数为负即 `E_UNEXPECTED` |
| 上限 | 单进程句柄数可配上限，超限拒绝 | 防泄漏蔓延 | `E_OUTOFMEMORY` + 日志 |

| 生命周期事件 | 引用计数变化 | 失败处置 |
|---|---|---|
| 资源创建命令 | +1 | 分配失败返回 `E_OUTOFMEMORY` |
| 绘制命令引用 | 0（只读引用） | 悬空即 `E_UNEXPECTED` |
| 资源更新命令 | 0，内容替换 | 失败时保留旧内容 |
| 资源释放命令 | −1 | 计数为负即 `E_UNEXPECTED` |
| 帧结束清理 / 引擎卸载 | 归零释放 / 全表释放 | 残留句柄进泄漏读数，`E_FAIL` |

### 3.4 IF-014 帧提交与窗口呈现通道

| 阶段 | 动作 | 成功判定 | 失败处置 | 读数 |
|---|---|---|---|---|
| 建目标 | 绑定 X11 窗口与后备缓冲 | 尺寸非零且与窗口一致 | `Win32Exception` | ACC-009 |
| 提交 | 命令批解码完成并生成帧 | 帧非空 | `E_FAIL`，ACC-007 红 | ACC-007 |
| 呈现 | 后备缓冲送到窗口 | 像素到达窗口 | 重试一次后报错 | ACC-007/008 |

| 白名单外动作 | 返回 D-Bus 错误回复，不得静默返回成功 |
| 文本读取与写入 | 读取返回完整文本与字符计数；写入只写节点自身文本、不级联子节点，写入后必须触发一次属性事件 |
| 观察点纪律 | 每个动作调用后必须抓到至少一个可观察变化，否则该动作判红（防「调用成功但什么都没发生」） |

## 8. 媒体（XIF-007）

### 8.1 IF-061 GStreamer 播放桥

| `playbin` 能力 | 用途 | 确认度 | 约定 |
|---|---|---|---|
| 源地址（URI） | 指定媒体 | 元素名已确证 | 只接受本地文件与登记协议 |
| 状态 | 四态映射（见下） | 四态已确证 | 状态只能沿合法边转移 |
| 总线消息 | 错误、结束、状态变化 | 总线机制已确证；消息结构待对拍确认 | 错误必须转成明确异常 |
| 时长与位置 | 进度反馈与定位 | 查询接口待对拍确认 | 未知时长返回「未知」而非 0 |

| GStreamer 状态 | 桥内语义 | WPF 侧可观察效果 | 进入条件 |
|---|---|---|---|
| `GST_STATE_NULL` | 关闭 | 媒体对象释放，读数归零 | 停止或关闭 |
| `GST_STATE_READY` | 就绪 | 已选源、未起管线 | 打开媒体成功 |
| `GST_STATE_PAUSED` | 暂停 | 画面停在当前帧，进度不变 | 暂停；播放前的预滚 |
| `GST_STATE_PLAYING` | 播放 | 进度前进、帧更新 | 播放 |

| 操作与探测 | 规则 |
|---|---|
| seek | 按时间定位，标志组合与接口签名待对拍确认；不可定位时返回明确错误，进度不回退 |
| 音量 | 写入 `playbin` 音量属性；越界值夹取并告警；属性不可写时返回错误 |
| 暂停后定位 | 定位后保持暂停，不自动续播；非法状态转移即拒绝（SM-006） |
| 版本探测 | 启动时读取 GStreamer 版本，低于 `1.20` 即登记不支持（R-006）；缺库时媒体入口返回明确错误，不影响其它子系统 |
| 不支持格式 | `playbin` 报错必须转成明确异常 + 缺陷编号，并由界面提示（SCR-06 `0/4` 可见且文本含编号）；**禁止静默返回空或停在就绪态** |
| 结束与错误 | 正常结束与解码错误必须是两个不同结果，不得合并成「结束」 |

## 9. 内部接口

### 9.1 IF-071 界面快照与检测探针

生成方 MOD-86；消费方 `50-verify/probe/` 与 `50-verify/a11y/`（TG-012）。

```json
 { "app": { "process": "WpfFirstWindow", "atspi_name": "WpfFirstWindow" }, "seq": 12,
   "window": { "id": "0x2a00007", "title": "WpfFirstWindow", "bounds": [0, 0, 1024, 768] },
   "env": { "session": "xvfb", "dpi": 96, "theme": "Aero2", "font_source": "fontconfig" },
   "nodes": [ { "path": "0", "role": "frame", "name": "WpfFirstWindow", "states": ["showing", "active"],
                "actions": ["focus"], "bounds": [0, 0, 1024, 768], "value": null, "relations": [], "child_count": 7 } ] }
```

| 顶层字段 | 必填 | 含义 | 判据用途 |
|---|---|---|---|
| `app` | 是 | 应用身份：进程名、程序集名、无障碍侧应用名 | 确认快照属于被测样本 |
| `window` | 是 | 窗口身份：窗口 id、标题、几何 | 结构 diff 的根 |
| `env` | 是 | 会话类型（xvfb/real/remote）、DPI、主题、字体来源 | 分叉归因（08 §3.1） |
| `seq` | 是 | 快照序号，同一运行内单调递增 | 对齐事件序列与帧序号 |
| `nodes` | 是 | 节点列表，按树序 | 逐行断言 |

| 节点字段 | 必填 | 含义 | 判据用途 |
|---|---|---|---|
| `path` | 是 | 由根按树序编号的数字段路径（`0/1/2`） | 结构 diff 的 join 键 |
| `role` | 是 | AT-SPI 角色（经 §3.12 映射） | 第一判据 |
| `name` | 是 | 可访问名称 | 第一判据，空名视为缺陷 |
| `states` | 是 | 状态位集合 | 第一判据 |
| `actions` | 是 | 可调用动作集合（§7.3 白名单） | 第一判据 |
| `bounds` | 是 | 屏幕绝对像素矩形（§2.2 口径） | 只比位置，不参与结构 diff |
| `value` | 否 | 文本值 | 第一判据 |
| `relations` | 是 | 标签、控制、成员关系 | 第一判据 |
| `child_count` | 是 | 子节点数，与 `nodes` 实际子数一致 | 结构 diff |

消费方按 `path` join 逐列比较，不读截图、不做文字识别；路径随树序变化，结构变化必须体现为 diff，不得由快照器抹平；缺必填字段的快照视为无效快照，判 `FAIL` 而不是 `SKIP`。

### 9.2 IF-072 缺陷登记写入

正文在 [《已知坑与降级清单》](../../70-operate/已知坑清单.md)，本接口只定写入形状与四要素。

| 字段 | 必填 | 取值 | 校验 | 失败处置 |
|---|---|---|---|---|
| 编号 | 是 | `D-`/`K-`/`X-` + 三位序号，全局唯一 | 不复用已删编号 | 重号即拒绝写入 |
| 触发条件 | 是 | 输入或环境描述 | 能被判据脚本复现 | 不可复现即退回 |
| 行为 | 是 | 返回码、降级路径、用户可见提示 | 必须含错误码或界面文案 | 缺返回码即退回 |
| 不做什么 | 是 | 明确排除的能力 | 非空 | 空即退回 |
| 判据 | 是 | `ACC-xxx` + 可执行命令 | 命令可执行 | 不可执行即退回 |
| 代码落点 | 是（实现期） | 文件与符号 | 与实现一致 | 不一致即 TG-014 红 |
| 状态 | 是 | 已定 / 待定 | 只追加，不改历史 | 改历史即红 |

| 只追加规则 | 内容 |
|---|---|
| 写入方式 | 追加新行或新节，不覆盖、不重排既有条目 |
| 删除 | 禁止删除，只能把状态改为「已定」并写明替代条目 |
| 唯一事实源 | 缺陷册正文唯一，其它文档只引用编号 |

### 9.3 IF-073 判据读数落盘

| 字段 | 类型 | 必填 | 含义 | 校验 |
|---|---|---|---|---|
| `acc` | 字符串 | 是 | 对应验收判据编号 | 必须在定义方出现过 |
| `tg` | 字符串 | 是 | 所属测试门 | 必须在 TG-001~TG-015 内 |
| `rc` | 整数 | 是 | 进程退出码 | 与 `verdict` 不矛盾 |
| `verdict` | 枚举 | 是 | `PASS` / `FAIL` / `SKIP` / `DEGRADED` | 只允许四值 |
| `started` | 时间 | 是 | 开始时间（UTC，带毫秒） | 可排序、可与实现提交时间比较 |
| `duration_ms` | 整数 | 是 | 耗时 | 大于等于 0 |
| `env` | 对象 | 是 | 运行环境快照 | 至少含会话类型、DPI、运行时版本、服务版本 |
| `expect_ref` | 字符串 | 是 | 期望文件定位（表 + 行键） | 指向存在的期望条目 |
| `diff` | 数组 | 是 | 差异条目，空数组表示无差异 | 与 `verdict` 一致 |
| `degrade` | 字符串或数组 | 是 | 允许的降级与豁免，无则写 `none` | `DEGRADED` 时必须非 `none` |

| 判定值 | 含义 | 计数口径 |
|---|---|---|
| `PASS` | 期望全部命中 | 计入通过 |
| `FAIL` | 任一期望未命中 | 计入失败，`diff` 必须非空 |
| `SKIP` | 因环境缺失未执行 | 单列，不计通过，必须写跳过原因 |
| `DEGRADED` | 执行但走了登记的降级路径 | 单列，必须带缺陷编号 |

落盘约定：一判据一文件，文件名为「时间戳 + 序号」；写入采用临时文件加改名，保证不出现半截文件；同一判据的历史读数只追加不覆盖。

## 10. 错误码总表

| 错误码 | 来源层 | 触发条件 | 用户可见行为 | 缺陷编号 |
|---|---|---|---|---|
| `E_NOTIMPL` | 能力层 | DRM 路径、`PresentationNative` 缺口入口、未实现动作 | 控制台错误行含入口名或编号；调用失败 | D-001（DRM）、其余待登记 |
| `E_INVALIDARG` | 调用层 | 句柄非法、未登记标志位、参数越界 | 调用失败并打印参数名与值 | 待登记 |
| `E_OUTOFMEMORY` | 资源层 | 资源表超限、位图或后备缓冲分配失败 | 明确失败；禁止部分绘制后假成功 | 待登记 |
| `E_UNEXPECTED` | 调用层 | 悬空句柄（代号不匹配）、引用计数为负 | 调用失败并打印句柄值 | 待登记 |
| `E_FAIL` | 解码层 | 未识别命令计数非 0、帧提交失败 | 渲染告警，ACC-006 红 | 待登记 |
| `HRESULT_FROM_WIN32(ERROR_MOD_NOT_FOUND)` | 装载层 | 自产 `.so` 缺失或装载失败 | 启动失败，错误行给库名与搜索路径 | 待登记 |
| `HRESULT_FROM_WIN32(ERROR_PROC_NOT_FOUND)` | 装载层 | 符号解析失败（清单与实现不一致） | 启动失败，错误行给符号名 | 待登记 |
| `HRESULT_FROM_WIN32(ERROR_NOT_FOUND)` | 资源层 | 字体族缺失、队列或作业不存在 | 明确失败；回退链命中记录为空 | 待登记 |
| `PlatformNotSupportedException` | 能力层 | 触达 `System.Drawing.Common` 的非 Windows 路径 | 异常含程序集名；控制台错误行 | R-003 处置项，待登记 |
| `Win32Exception` | 窗口层 | X11 连接断开、权限不足 | 窗口关闭路径，进程退出码非 0 | 待登记 |
| `InvalidOperationException` | 状态层 | 非法状态转移（未就绪即定位、已卸载再提交） | 操作被拒，状态不变，读数记 `FAIL` | 待登记 |
| `NotSupportedException` | 能力层 | 媒体格式不支持、GDI+ 特效不支持 | 界面提示可见且含缺陷编号 | 待登记 |
| `PrintQueueException` | 能力层 | 无 CUPS、队列不可达、作业被拒 | 打印失败并给出队列名 | 待登记 |

「待登记」表示按 ADR-012 必须在实现落点登记缺陷册编号；当前缺陷册仅 `D-001`、`K-001` 两条，登记时由 IF-072 统一分配。
