## 2 抽取与筛选

**进了本体的（按判据）**：满足三条中的两条以上——①被至少一条规则引用；②有契约落点（IF/TBL/模块）；③能被判据读数观测。

**没进的（12 条 `excluded`，理由原文在 yaml）**：

| 概念 | 为什么排除 |
|---|---|
| 二进制兼容（PE 加载/身份仿真） | ADR-001 明确非目标 |
| WinForms 设计器 | UD-004 裁决不做 |
| ActiveX/DCOM 宿主 | 只做进程内 COM 桩 |
| DRM 内容播放 | DQ-001：`E_NOTIMPL` + D-001 |
| Wayland 后端 | V2 扩展，V1 判据不含 |
| arm64 | V2 扩展，V1 只覆盖 x64 |
| GPU 渲染后端 | ADR-004：先有落点再谈性能 |
| GTK/Qt 主题映射 | ADR-010：只做原主题视觉复刻 |
| Windows IME 协议（IMM32/Tsf） | ADR-008：接 ibus/fcitx5 |
| WMP/Media Foundation 全格式 | ADR-009：以 GStreamer 能力为准 |
| 用户权限与访问控制模型 | 单用户桌面会话 |
| 数据库/持久化存储 | 本项目无数据库；契约文件与读数 JSON 即数据面 |

**被合并的（不单列类）**：窗口句柄与 GDI 句柄都归入 `C008 资源句柄` 的 `type` 枚举；AT-SPI 事件并入 `C015` 的 `states`/`actions` 变化；三个 `.so` 的装载细节归入 `C012`/`C013`，不单独建「原生库」类（否则类会超 25）。

## 5 置信度为什么没有 `high`

- 项目尚无任何实测判据读数（`50-verify/读数/` 未产生），规则全部由设计文档推导。
- 3 条 `low` 都指向未闭合的上游事实或缺口：`R036`（GAP-003）、`R038`（D06 已裁决但实读数未有）、`R039`（D07 已裁决仍待 TG-001 对拍）。口径裁决 ≠ 实现验证。
- 升级条件：某条规则对应的判据在 `50-verify/读数/` 出现连续两次 `PASS`，才可升为 `high`；升级同时要改 [#业务本体](ontology.yaml) 与本节。
