# 术语表

> §1 是**一物多名的统一口径**：第一列是首选名称，写文档、画图、提验收一律用它；第二列只用于引用方案原文或历史记录。
> **软件与宿主分两张表**：软件是「跑的东西」，宿主是「装它的机器或运行环境」。
> 机器可读版本见 [#名称清单](../30-design/model/names.json)；人读以本文为准，两者冲突时改机器版对齐本文。

## 1. 同物异名

|---|---|---|

## 2. 项目内部叫法

- **三条契约**：P/Invoke C ABI、DUCE 字节流、pack 清单。**不写「三个接口」**（接口在本项目专指 XIF）。
- **四个契约文件**：`exports.txt`、`win32_abi.h`、DUCE 布局表、`FrameworkList`。它们是仓内一等资产，改一处必须同步对拍。
- **八子系统**：wpf-port、native-shim、milcore、text-stack、wic-dwrite、pack、winforms-compat、service-adapters。
- **12 项专有面**：DWM、UIA、XPS、DRM、DirectWrite 特性、字体回退、IME、DPI、主题、Ribbon、Media、Ink；编号与落点见 [《概要设计》](../30-design/概要设计.md) §5。
- **核心六控件**：Button、TextBox、ListBox、ComboBox、Form、Menu；WinForms 兼容层的最低验收边界（DQ-003）。**常用控件**也要求可用；未实现的控件走「控制台报错 + 空白占位」，不崩溃。
- **项目定位**：**WindowsDesktop 在 Linux 上源码级完整运行**；范围＝WPF 全量 + WinForms 兼容层。**不写「WPF 在 Linux 上完整运行」**——那只是定位的一部分，WinForms 与框架包同样在范围内。
- **本体**：`本体/` 下的运行时对象模型（类／关系／规则／动作／术语／裁决），入口是[《本体说明》](../本体/本体说明.md)。**不写「知识图谱」**（那是检索形态，不是本仓的建模产物），也不写「业务本体」（本项目没有业务对象，只有运行时对象）。
- **DQ-001~004**：四项裁决（2026-10-30 关闭），见 [《决策记录》](决策记录.md) §2。
- **五个检查器**：链接、文档包、编号、覆盖、自检；见 [《引用与名称规范》](引用与名称规范.md) §6。
- **测试门与三判据**：TG-001~TG-015；契约对拍、结构判据、帧判据三层顺序不颠倒（ADR-014/015）。
- **两阶段平台**：V1 = x64/X11；V2 = Wayland/arm64。
- **源级重编 vs 二进制兼容**：本项目只做前者；后者是明确非目标（ADR-001）。

## 3. 缩略语

- **ABI**：应用二进制接口；本项目特指 C 函数签名与结构体布局。
- **ADR**：架构决策记录；[《概要设计》](../30-design/概要设计.md) §3，编号 ADR-001~015。
- **ACC**：验收准则；[《需求与验收判据文档》](../20-spec/需求与验收判据文档.md) §9，编号 ACC-001~030。
- **AT-SPI**：Assistive Technology Service Provider Interface；Linux 无障碍总线，UIA 的替代落点。
- **CSCI**：计算机软件配置项；本项目用 8 个 CSCI 标签（CSCI-PORT 等）归并 38 个模块，见[《03-软件设计说明》](../30-design/设计文档包/03-软件设计说明.md) §9。**不是受管编号**，不单独分配编号。
- **S0~S7**：开工切片标签（S0 冻结 → S7 全量验收，与概设 §12 的 M0~M7 一一对应），见[《09-开工前置与切片计划》](../30-design/设计文档包/09-开工前置与切片计划.md) §6。**不是受管编号**。
- **B1~B10**：开工阻塞项标签（编码前的必关闭项），见[《09-开工前置与切片计划》](../30-design/设计文档包/09-开工前置与切片计划.md) §2.1。**不是受管编号**。
- **GAP**：界面或契约缺口；编号 GAP-001~012，定义在[《界面设计说明》](../30-design/设计文档包/界面设计说明.md) §9.3。
- **IF**：接口；编号 IF-001~IF-073，定义在[《04-接口设计说明》](../30-design/设计文档包/04-接口设计说明.md)。
- **SAFE**：安全要求；编号 SAFE-001~020，定义在[《06-安全性设计支撑材料》](../30-design/设计文档包/06-安全性设计支撑材料.md) §2。
- **SCR**：可检测界面；编号 SCR-01~SCR-07，定义在[《界面设计说明》](../30-design/设计文档包/界面设计说明.md) §1。
- **SM**：状态机；编号 SM-001~SM-008，定义在[《03-软件设计说明》](../30-design/设计文档包/03-软件设计说明.md) §4。
- **TBL**：契约清单、运行时表与读数表；编号 TBL-001~TBL-012，定义在[《05-数据与清单设计说明》](../30-design/设计文档包/05-数据与清单设计说明.md) §3。
- **TG**：测试门；编号 TG-001~TG-015，定义在[《08-判据先行与界面检测设计说明》](../30-design/设计文档包/08-判据先行与界面检测设计说明.md) §2。
- **DUCE**：Dynamic Universal Composition Engine 的命令流；WPF 的 MIL 内部协议。
- **DWM**：Desktop Window Manager；Windows 合成器。
- **DPI**：每英寸点数；本项目指 per-monitor 缩放。
- **ICC**：色彩特性文件；`mscms` 的替代走 lcms2。
- **IME**：输入法编辑器；本项目接 ibus/fcitx5。
- **LGPL**：GNU 宽通用公共许可证；GStreamer 的许可。
- **MIT**：上游与新增代码的许可。
- **MSAA**：Microsoft Active Accessibility；WinForms 无障碍接口，替代为 AT-SPI 桥。
- **OFL**：SIL Open Font License；字体许可。
- **PTS**：Presentation Text System。
- **RID**：Runtime Identifier；`linux-x64`、`win-x64`。
- **UIA**：UI Automation；WPF 无障碍接口，替代为 AT-SPI 桥。
- **WIC**：Windows Imaging Component；替代为 `libwpfwic.so`。
- **XPS**：XML Paper Specification；打印路径的文档格式。

## 4. 命名纪律

1. **首选名唯一**：同一事物在正文、图、表、判据里只用首选名；异名只出现在「引用历史记录」时。
2. **不新造缩写**：新增缩写必须先在本表登记，并在首次出现处写全称。
3. **软件与宿主不混用**：不写「X11 跑起来」（X11 是服务器，跑的是应用）；不写「SDK 编译了窗口」（SDK 编译的是代码）。
4. **编号即引用**：REQ/ACC/ADR/MOD/DQ/R 首次定义后在全文只用编号，不重述内容。
