## 一、Ink 笔光标闭环（缺 `IMILRenderTargetBitmap`）

### 1.1 现状与根因

**失败栈**（实测，K-446）：
```
at MS.Internal.HRESULT.Check(Int32 hr)
at System.Windows.Media.Imaging.BitmapVisualManager.Render(Visual, Matrix, Rect)
at System.Windows.Media.Imaging.RenderTargetBitmap.Render(Visual)
at MS.Internal.Ink.PenCursorManager.RenderVisualToBitmap(...)
```

**源码位置**：`PresentationCore/System/Windows/Media/Imaging/BitmapVisualManager.cs:59-140`

```csharp
internal void Render(Visual visual, Matrix worldTransform, Rect windowClip)
{
    ...
    SafeMILHandle renderTargetBitmap = _bitmapTarget.MILRenderTarget;
    Guid iidRTB = MILGuidData.IID_IMILRenderTargetBitmap;
    HRESULT.Check(UnsafeNativeMethods.MILUnknown.QueryInterface(
        renderTargetBitmap, ref iidRTB, out pIRenderTargetBitmap));   // ← 失败点
    Renderer.Render(pIRenderTargetBitmap, ...);
}
```

**⇒ `QueryInterface(IID_IMILRenderTargetBitmap)` 返回 `E_NOINTERFACE`。**

### 1.2 需要实现的能力

| # | 能力 | 源码位置 | 为什么需要 | 工作量 |
|---|---|---|---|---|
| **A** | **`IMILRenderTargetBitmap` COM 接口** | `WpfGfx/core/meta/dummyrt.cpp:118`（`DummyRT` 实现了它）、`WpfGfx/core/sw/swsurfrt.h:326`（`SwSurfaceRT` 也实现） | `BitmapVisualManager.Render` 必须 `QueryInterface` 成功 | **中~大（需逆向 vtable）** |
| **B** | `IMILRenderTarget`（父接口） | `WpfGfx/include/wgx_render.h:149` | `IMILRenderTargetBitmap` 继承链 | 中 |
| **C** | `IRenderTargetInternal` | `dummyrt.cpp:112` | `DummyRT` 的另一个接口 | 中 |
| **D** | `IWGXBitmapSource` | `dummyrt.cpp:127` | 从 MIL 转 WIC 的桥 | 中 |

### 1.3 参考实现（可直接读源码对齐）

**WPF 自己的 `DummyRT`（`WpfGfx/core/meta/dummyrt.cpp`）实现了全套接口**，
包括 `QueryInterface` 的 6 个分支：
```cpp
if (riid == IID_IUnknown)              { *ppvObject = static_cast<IUnknown*>(...); }
else if (riid == IID_IMILRenderTarget) { *ppvObject = static_cast<IMILRenderTarget*>(...); }
else if (riid == IID_IRenderTargetInternal) { ... }
else if (riid == IID_IMILRenderTargetBitmap) { ... }   // ← 我们要的这个
else if (riid == IID_IMILRenderTargetHWND) { ... }
else if (riid == IID_IWGXBitmapSource) { ... }
```

**⇒ **关键洞察**：`DummyRT` 是**空实现**（「dummy」），所以**实现 `IMILRenderTargetBitmap` 不一定要真的渲染** —— 只需让 `QueryInterface` 成功、核心方法返回合理值。

### 1.4 验证方式

**埋点**：在 `libwpfwin32.so` 里导出 `IMILRenderTargetBitmap` 相关的 `MilResource_*`，
或用 `LD_PRELOAD` 拦截 `QueryInterface`，打印 `riid` —— **这样能确认 WPF 到底要哪些接口**。

**实测判据**：`BitmapVisualManager.Render` 那一帧从栈里消失（和 K-426/K-427 的方法一样）。

## 六、P0 的具体做法（可执行）

### 6.1 先确认 WPF 要哪些接口（埋点）

**方法**：在 `libwpfwin32.so` 里加一个 `QueryInterface` 的 hook（或用 `LD_PRELOAD` 包装 `MILUnknown_QueryInterface`），打印 `riid`。

**判据**：看到 `IID_IMILRenderTargetBitmap` 的 GUID。

### 6.2 找到 GUID

**源码位置**：`MILGuidData.IID_IMILRenderTargetBitmap`（`PresentationCore` 的 `MILGuidData.cs`）

**⇒ 需要读源码拿到确切 GUID**（下一步）。

### 6.3 实现最小可用版

**参考 `DummyRT`**（`WpfGfx/core/meta/dummyrt.cpp`）：
- `QueryInterface` 返回自身（6 个 IID 分支）
- 其他方法返回 `S_OK` / `E_NOTIMPL`（**不真的渲染**）

**⇒ 目标是让 `QueryInterface` 成功，不是让 `Renderer.Render` 真的工作。**

**⇒ 如果 `Renderer.Render` 内部还需要别的，再逐层补。**
