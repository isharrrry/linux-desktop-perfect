# 缺口影响对照表（谁调不到 → 影响什么 → 怎么回退）

> **本表回答一个问题**：「Windows 编译的 WindowsDesktop 程序拿到 Linux 上直接跑，某一项缺失会造成什么后果？」
>
> 口径分三类，**必须分清**：
> - **A 类｜有替代**：有 Linux 对应物，已真实现 ⇒ **不影响运行**
> - **B 类｜无替代但已降级**：已导出为桩，返回安全值 ⇒ **不影响"跑起来"，但相关功能不可用，且调用方能检测到**
> - **C 类｜未实现（gap）**：符号不存在 ⇒ **一调就崩（`EntryPointNotFoundException`）**。**这是最严重的一类，本表目标是把 C 类清零。**
>
> 生成方式：`awk -F'\t' '$1=="libwpfwin32.so"&&$3=="gap"' 40-build/native-shim/exports.txt`
> 当前状态：**A 类 22 / B 类 110 / C 类 0（待 A 类补完后为 0）**

## 三、怎么验证「不影响跑起来」

```bash
# 1) 确认没有 C 类（gap 必须为 0）
awk -F'\t' '$1=="libwpfwin32.so" && $3=="gap"' 40-build/native-shim/exports.txt | wc -l   # 期望 0

# 2) 确认 .so 里这些符号都在（B 类也不能缺）
for s in FsCreateSubpageBottomless CreateRecognizer AccessibleObjectFromWindow; do
  nm -D 40-build/native-shim/bin/libwpfwin32.so | grep -qw "$s" || echo "缺: $s"
done

# 3) 跑样本，确认没有 EntryPointNotFoundException
DISPLAY=:303 ... dotnet samples/WinFormsBasics/bin/Release/net10.0/WinFormsBasics.dll 2>&1 | grep -c EntryPointNotFound
```
