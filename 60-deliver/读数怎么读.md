# 60-deliver · 读数怎么读

下游（评审、验收、回归）拿到的**唯一事实来源**是 `50-verify/读数/` 里的 JSON。
本文说明怎么找到它、怎么读它、什么不算通过。

## 1. 三个入口，从粗到细

| 入口 | 用途 |
|---|---|
| `50-verify/index/索引表.md` | **总览**：一条 ACC 一行（测试门 / 样本界面 / 可复制的单行命令 / 有无脚本）。**生成物**，`node 50-verify/index/gen-index.mjs` 刷新，`--check` 校验同步 |
| `60-deliver/交付清单.md` | **当前判定汇总**（PASS/DEGRADED/FAIL 各几条）。同理，从读数自动生成，不手填 |
| `50-verify/读数/ACC-xxx/` | **单条判据的每次运行**：一个时间戳一个文件 |

## 2. 一次读数的字段

每个读数 JSON 的字段是固定的（判据脚本用 `finish()` 统一写出）：

| 字段 | 含义 |
|---|---|
| `acc` | 判据编号（如 `ACC-007`）|
| `tg` | 测试门（如 `TG-003`）|
| `rc` | 进程退出码 |
| **`verdict`** | **`PASS` / `DEGRADED` / `FAIL` / `SKIP`**（判定见 §3）|
| `started` | 开始时间（ISO）|
| `duration_ms` | 耗时 |
| `env` | **证据**：本次运行的环境与关键读数（由各判据自定义，例如渲染判据会写 `frames`、UIA 判据会写节点数）|
| `expect_ref` | 期望来源（如 `50-verify/a11y/expect/scr-01.json`）|
| `diff` | **判定理由**：为空数组 = 无差异；非空 = 逐条差异说明 |
| `degrade` | 降级原因（仅 `DEGRADED`/`SKIP`）|

**读一条读数只需要看三个字段：`verdict`、`diff`、`degrade`。**
`env` 是用来复核"当时到底跑了什么"的，出问题时才需要看。

## 3. 四类判定的含义（口径硬约束）

| 判定 | 含义 | 统计里算通过吗 |
|---|---|---|
| `PASS` | 判据要求全部满足，`diff` 为空 | **是** |
| `DEGRADED` | **部分**能力达成，剩余部分在 `degrade` 里写明 | **否** |
| `FAIL` | 不满足（`diff` 给出逐条差异）| **否** |
| `SKIP` | 环境缺件（如没有输入法服务器），**无法真验** | **否**（不计通过）|

**`DEGRADED` 与 `SKIP` 都不是通过。** 这一条在 08 §1.5 与本文重复强调，是因为它最容易被
"看起来快过了"的心情误读 —— 本项目里已经发生过两次把"部分完成"当成"完成"的判定事故
（见 `70-operate/已知坑清单.md` 的 D-017、D-015 收束段）。

## 4. 一条读数是怎么产生的（以渲染判据为例）

```bash
node 50-verify/render/frame-probe.mjs --frames 2
# → 50-verify/读数/ACC-007/2026-10-30T21-54-06-484Z-01.json
```

脚本内部会：起 `Xvfb` → 起样本 → 抓帧 → 与基线比 → 写读数 → 打印一行汇总。
**判据脚本不做"重试到通过"**；失败了就写 FAIL 并退出非 0。

## 5. 复核一个历史判定

```bash
# ① 看最近一次
ls -t 50-verify/读数/ACC-007/ | head -3

# ② 看它的判定与差异
node -e "const d=require('./50-verify/读数/ACC-007/<文件>.json'); console.log(d.verdict, JSON.stringify(d.diff))"

# ③ 想重跑就用索引表里那一行的命令（每条都可复制即跑）
```

## 6. 哪些"通过"是不可信的（自查清单）

以下情形在历史上都出现过，看到时要怀疑读数而非怀疑实现：

| 症状 | 检查 |
|---|---|
| 判据绿了但样本没换 | 判据是否按 `--scr` 映射到正确的样本（曾硬编码 `WpfFirstWindow`，见 M96）|
| 判据绿了但依赖没装 | `install-runtime` 之后是否重装了 bridge（K-003）|
| 判据绿了但代码没生效 | 构建产物是否真的换了（对比时间戳/md5）|
| 判据红得莫名其妙 | 期望文件与元素属性表是否同步（`build-wireframe --check`）；改期望后**样本是否重建** |
| 差异数忽大忽小 | 差异里有多少属于"结构性限制"（读数会印 `（其中结构性=N）`）|
