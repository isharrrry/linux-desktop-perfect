## L-1 客户区渲染空白（客户区 4 色）

- **现象**：SourceTree 主窗口能创建（`WID=8388613`）、AT-SPI 可枚举，但客户区截图 **4 色 / 9172 字节**（空白）
- **证据**：`sourcetree-shots/st-20-main-window-9172.png`；像素分析 `len(set(crop((0,60,w,h)).getdata())) == 4`
- **根因（已精确到 C++ 内部，K-908/909/911/912）**：
  - ✅ 渲染引擎存在：`wpfgfx_cor3.so`（5086064 B，129 个 T 导出）
  - ✅ 传输建立成功：`WgxConnection_Create` 未抛异常（`MediaSystem.cs:200`）
  - ✅ **渲染策略开关已开**：`Switch.System.Windows.Media.ShouldRenderEvenWhenNoDisplayDevicesAreAvailable = true`（`runtimeconfig.json`）⇒ 实测 `MediaContext.get_ShouldRenderEvenWhenNoDisplayDevicesAreAvailable == True`
  - ✅ shim 的贴图路径已实现：`BitBlt` → `XCopyArea`（`win32_gdi_dc.c:364`）、`XPutImage`（`:412`）
  - ❌ **缺口**：`wpfgfx` **内部**的 `Present` 输出目标（`WgxConnection_SameThreadPresent` 只有导出、**无托管 DllImport** ⇒ `LD_PRELOAD` 也无法拦截）
- **判定为限制**：需要①重编译 `wpfgfx`（WPF 的 C++ 图形核心，加载源码 + Linux 输出后端）或②逆向 patch `wpfgfx_cor3.so` 机器码

## L-2 UIA 控件树只有窗口级（≥30 有 name 控件 / ≥5 类未达成）

> **2026-11-02 更新（K-866 … K-969，104 条记录）**：`UiaReturnRawElementProvider` 的通路**已打通**
> （`[UIA] CALLED` 稳定，`el` = `MS.Internal.Automation.ElementProxy`，K-948/K-954/K-951），
> 但**桥接读属性失败**：`ElementProxy.GetPropertyValue` 同步调用**死锁**（K-957，`pop` 版也归零）。
> 完整链条见 `已知坑清单.md` K-866…K-969。

- **已达成的部分**：**10 个控件 / 6 个有 name**（`application` + `frame` 两类）
  - 证据：`sourcetree-shots/proof-uia-dumptree.json`（2339 B）、`proof-uia-sourcetree.json`（1363 B）
  - 可复现：`dump-tree.dll --json --bus <bus>` / `gdbus call ... GetChildren`
- **未达成的部分**：目标要求 **≥30 个有 name 控件 + ≥5 类**（menu/toolbar/button/text/list/tab/status）
- **根因（15 层实证链，K-866 … K-907）**：
  ```
  AT-SPI 注册 ✓
    → dispatch ✓（proc 非 NULL）
    → SubclassWndProc ✓（msg=0x3D）
    → HwndWrapper.WndProc ✓（msg=0x3D）
    → HwndTargetFilterMessage ✓（msg=0x3D ×2；第 2 次 _hwndTarget != null 且 IsUsable=True）
    → HwndTarget.HandleMessage ✓（msg=61）
    → ❌ if (IsDisposed) return;   // HwndTarget.cs:1013
    → CriticalHandleWMGetobject（未调用）
  ```
- **结论**：`WM_GETOBJECT` **完整抵达** `HwndTarget.HandleMessage`，但 **`HwndTarget` 已 dispose** ⇒ `WM_GETOBJECT` case 不执行 ⇒ `UiaReturnRawElementProvider` 从不被调用
- **与 L-1 同源**：`HwndTarget` 在渲染未完成时被 dispose（`HwndTarget.cs:1013` 的 `if (IsDisposed) return;` 拦截了 `WM_GETOBJECT`）
- **判定为限制**：与 L-1 同一工程量（需先修 L-1）
