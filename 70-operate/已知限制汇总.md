> **2026-11-02**

**根本原因（实测）：**
```
nm -D wpfgfx_cor3.so | grep -ic "x11|drm|egl|vulkan|glx|opengl"  →  0
ldd wpfgfx_cor3.so | grep -i "X11|GL|EGL|drm"                     →  （无）
```

**⇒ `wpfgfx_cor3.so`（131 导出）**没有任何 Linux 图形后端符号或依赖** ⇒ 它是 **Windows 版二进制改扩展名**。**
