## 五、完整可复现链路

```bash
# 1. 修 Gong..cctor（异常源）
APP=<app目录> sh 40-build/appliers/gong-dnd/apply.sh

# 2. 构建 shim（含 SHGetStockIconInfo + AT-SPI Action）
cd 40-build/native-shim && ./build-shim.sh     # → 783768 / md5 d40aa83d
cp bin/libwpfwin32.so $FX/libwpfwin32.so

# 3. Cecil 注入（tab-fix + ReopenTabs + AddOrActivate + InvokeScan）
#    源码：50-verify/external/uia/cecil-tools/tab-activate.cs
rre.bin <SourceTree.exe> <out.dll> <PresentationFramework.dll> <app目录>

# 4. 运行 + 抓图
DISPLAY=:303 xwd -id <WID> -silent -out f.xwd && convert f.xwd f.png
# ⇒ 34955~37801 字节 / 517~518 色
```

## 七、结论

**本项目在「不引入 wine/mono、只用本仓 shim + 官方 .NET 10 WPF + Cecil patch」的约束下：**

**已达成（可复现、有实测证据）：**
- UIA 枚举 151 控件 / 14 类 / 完整序列
- 七大菜单 name 7/7 + role + 展开截图
- Invoke 真正触发（`INVOKED ok`）
- 提交列表填充 16 提交（37801B / 518 色）
- AT-SPI frame name 9/9
- 真实界面截图 5/10 达标
- shim 可构建可复现（md5 一致）

**未达成（有明确技术障碍）：**
- Add 表单（L-14，7 方案全失败）
- 子窗口 >20000B 截图（L-13，尺寸锁死）
- 多窗口同时渲染（K-1121）
- 工具栏五按钮 / 搜索框 / 状态栏名（控件不存在或无文本）
- AT-SPI Action 端到端（pyatspi 侧未通）

**所有「未达成」都不是「没做」，而是「做了、失败、有具体异常名 + K 号记录」。**
