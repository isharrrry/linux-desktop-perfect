## 1. 项目背景与目标

### 1.1 背景

WPF 的托管层 MIT 开源，但运行时依赖四类非托管面：闭源 redist（`PresentationNative`、`PresentationCFFRasterizerNative`）、开源但绑定 Windows 的 native（`wpfgfx`、`PenImc`、`DirectWriteForwarder`）、Windows OS 服务（GDI+、USER32、DirectWrite、WIC、UIAutomation、DWM、MsDrm、PrntvPt）、以及只发 `win-*` RID 的框架包。

现有 `WPFOnLinux` 已验证「源码级重编 + 自写 Win32 shim + 自写 MIL 后端」这条路可行，但资产散在托管源、C shim、构建编排三处，且 MIL 源码未入库。本项目把这些资产收敛为一个单仓、四个子系统、一套可复算判据。

### 1.2 目标

1. **源码级完整**：一份 WindowsDesktop 应用源码工程（WPF 全量、WinForms 到兼容层）在 Linux x64/X11 上 `dotnet build` 通过、启动、交互、打印、无障碍可用。
2. **框架级接入**：不改工程文件，`<UseWPF>true</UseWPF>` 解析到自产 `Microsoft.WindowsDesktop.App` pack。
3. **每一项有落点或降级**：WPF 的 12 类 Windows 专有路径（见 §4）每条都有 Linux 实现或一条显式记录的降级，禁止静默失败。
4. **可复算**：每条 ACC 都有单行命令或唯一入口，读数带时间戳。
5. **可持续**：上游只读 + applier 再生，不产生不可合并的树内手改。

### 1.3 与既有资产的继承关系

| 资产 | 位置 | 处置 |
|---|---|---|
| WPF 托管源快照 | `WPFOnLinux/src/Microsoft.DotNet.Wpf/` | 迁入 `40-build/upstream/wpf/`，只读 |
| C shim | `WPFOnLinux/src/WpfGfx.Linux.Native/`（56 文件 / 25,734 行） | 迁入 `40-build/native-shim/`，ABI 契约独立版本化 |
| MIL 后端 | `WPFOnLinux/src/WpfGfx.Linux/`（git 0 tracked） | **迁入前补源码**（DQ-002） |
| 构建编排与判据 | `WPFOnLinux/src/Linux/build/`（2,522 tracked） | 迁入 `40-build/`，保留 MilBridge 与验收入口 |
| 托管侧替代 | `PtsCache.Linux.cs`、`FontLayoutStripping`、`PBT.Linux` | 留 `40-build/wpf-port/`，不跨进程边界 |
| 旧缺陷册与波次记录 | `WPFOnLinux/docs/` | 归档到 `90-archive/wpfonlinux/`，只读引用 |

## 2. 范围

### 2.1 范围内

- WPF 托管层（`PresentationFramework` / `PresentationCore` / `WindowsBase` / `System.Xaml` / `PresentationUI` / `ReachFramework` / `System.Printing` / Ribbon / UIAutomation / `WindowsFormsIntegration`）在 Linux 上编译与运行。
- 12 类 Windows 专有面：DWM、UIA、XPS 打印、DRM（降级 D-001）、DirectWrite 特性、字体回退、输入法、DPI、Aero/Luna/Royale/Classic 主题、Ribbon、Media、Ink。
- 框架包：`Microsoft.WindowsDesktop.App.Ref` / `Microsoft.WindowsDesktop.App.Runtime.linux-x64`（WPF Profile）。
- WinForms **兼容层**：加载、基础控件、MSAA→AT-SPI 桥。

### 2.2 范围外

- 二进制兼容（Windows 编的 dll/exe 直接跑）。
- WinForms 控件树重写、VS 设计器、ActiveX/DCOM 宿主。
- Windows IME 协议（IMM32/Tsf）仿真。
- WMP/Media Foundation 全格式覆盖；DRM 内容播放。
- Windows 主题映射到 GTK/Qt；只做 WPF 原主题视觉复刻。
- .NET Framework（4.x）支持；只做 .NET 10。
- Wayland、arm64（V2 平台扩展，不在 V1 判据内）。

## 3. 术语

| 术语 | 含义 |
|---|---|
| DUCE | MIL 的绘制命令流；`wpfgfx` 与托管层的唯一契约（118 条命令） |
| PTS | Presentation Text System；`PresentationNative` 里的行布局/段落引擎 |
| LineServices | PTS 依赖的文本行服务（`Lo*`/`Fs*`/`Nl*` 入口） |
| 自产件 | 本仓构建出的托管程序集与 `.so`，与官方件同名同身份 |
| pack | `Microsoft.WindowsDesktop.App.Ref` / `.Runtime.*` 的合称 |
| 诚实降级 | 不可实现路径返回明确错误码并在缺陷册登记，不静默返回空 |
